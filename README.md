# logo_bootcamp_agentes_IA
Logotipo criado com auxílio de inteligência artificial, utilizando o ChatGPT (modelo GPT-6, da OpenAI) para elaboração do prompt e a ferramenta de geração de imagens integrada ao ChatGPT. A identidade visual foi inspirada nas cores da empresa, com elementos que representam inteligência artificial, automação e sistemas multiagentes.
